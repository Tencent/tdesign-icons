# TDesign Icons View

## 🧐 Introduction

- A package for display all TDesign icons in any UI framework

## 📦 Installation

- `npm i tdesign-icons-view`

## 🔨 Usage

```js
import "tdesign-icons-view";

// single page
<td-icons-view />;
// inserted as part of page
<td-icons-view framework-content />;
```
